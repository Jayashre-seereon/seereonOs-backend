## Where CEO v7 points meet the guide, and how each was resolved
- §7 Tasks tab vs point 5: the guide says "lists every task with filters by person, project and status". The CEO's v7 rule is explicit and newer, so it decides visibility. Employees see tasks they own, cover, back up, review, are concerned manager / PM / assigner / watcher of, or were @mentioned on. tasks.view_all (CEO, Administrator, PM, HR, Sales Manager) sees every task. Everyone gets the same "Tasks" page with the same columns and the Person / Project / Status filters. The project WBS still lists every task, and dependencies still name the blocking task and its owner.
- §4 milestone billing vs point 9: Not due / Invoiced / Paid are unchanged. Choosing Invoiced opens the GST invoice editor, prefilled from the milestone. Issuing it marks the milestone Invoiced, and the ledger gets "Milestone invoice" income at the taxable value. Choosing Paid opens the payment dialog, and paying in full marks the milestone Paid. An invoiced milestone still can't be deleted.
- §6 / §13 revenue: Actual margin, P&L "billed" and ledger income use the taxable value. GST is a separate liability. For the seeded projects, the planned, projected and actual margins (and P&L / ledger) match the v6 and v7-core builds exactly.
- §3 point 4: the create form keeps its costing calculator. The standalone Projects & WBS › Project cost calculator is an addition. One thing to note: Sales Manager has estimates.manage. Named people's rates are masked unless the user can see salaries, but an estimate with a single named person reveals that person's cost through the total.
- Point 3 sidebar: every guide tab is still a menu item (grouped). Project tabs can also be reached as Projects & WBS submenus.
